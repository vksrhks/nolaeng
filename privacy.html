개인정보처리방침

놀랭 업로더 · 시행일: 2026년 11월 9일

"놀랭 업로더"(이하 "앱")는 YouTube 채널 "놀랭(놀라운 랭킹)"의 운영자가 직접 제작한 영상을 본인의 YouTube 채널에 업로드하기 위해 사용하는 개인용 프로그램입니다.

1. 수집하는 정보

앱은 Google OAuth를 통해 운영자 본인이 허용한 YouTube 업로드 권한(youtube.upload)만 사용합니다. 이름, 이메일, 연락처 등 개인정보를 수집하거나 저장하지 않습니다.

2. 정보의 이용

부여받은 권한은 운영자 본인의 채널에 영상을 업로드하는 용도로만 사용합니다. 다른 사용자의 데이터에는 접근하지 않습니다.

3. 저장 및 보관

로그인 인증 토큰은 운영자의 개인 컴퓨터에만 저장되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다.

4. 제3자 제공

앱은 어떤 정보도 제3자에게 제공하거나 판매하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책 (제한적 사용 요구사항 포함)을 따릅니다. YouTube API 서비스를 사용하므로 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

6. 권한 철회

언제든지 Google 계정 보안 설정에서 앱의 접근 권한을 철회할 수 있습니다.

7. 문의

YouTube 채널 "놀랭(놀라운 랭킹)"을 통해 문의할 수 있습니다.
